# ATM System - System Analysis and Design (SAD)

This repository contains the complete system analysis and design documentation for an **Automated Teller Machine (ATM) System**. This project focuses on modeling the core functionalities of a banking interface, ensuring a secure, fast, and user-friendly experience for customers.

## 📌 Project Overview
The ATM System is designed to act as a software-based interface between bank customers and the central banking server. The goal of this project was to produce a consistent and well-documented system design deliverable following industry-standard UML practices.

### Core Functionalities
- **User Authentication:** Secure login via Card and PIN validation.
- **Cash Operations:** Withdrawal and Deposit processing.
- **Account Management:** Fund transfers and Balance inquiries.
- **Session Handling:** Receipt printing and secure session termination.

## 🛠 Methodology & Design Artifacts
The project follows a structured design approach, including:

- **Requirement Analysis:** Functional and non-functional requirements gathered via direct observation and AI-assisted user simulation.
- **Process Modeling:** Context Diagrams and Data Flow Diagrams (DFD).
- **Use Case Modeling:** Detailed use case diagrams and descriptive analysis for all main flows and alternative scenarios (e.g., invalid PIN, insufficient funds).
- **Dynamic Modeling:** 
  - **Activity Diagrams** to visualize system workflows.
  - **Sequence Diagrams** for detailed interaction between the User, ATM, and Bank System.
- **Static Modeling:** A comprehensive **Class Diagram** defining the system architecture.

## 🔒 Key Design Considerations
- **Security:** 3-attempt PIN locking and encrypted communications.
- **Performance:** Authentication under 5 seconds and intuitive UI design.
- **Reliability:** Designed for 99.9% availability.
